# 🎱 Billiard Master Simulation — Week 1: Requirements & Planning

**Billiard Master** adalah simulasi permainan biliar **8-ball** berbasis desktop yang dikembangkan menggunakan **Python** dan **Pygame**. Proyek ini dirancang sebagai **Final Project** untuk mata kuliah **Desain dan Pemrograman Berorientasi Objek** serta **Rekayasa Perangkat Lunak**.

---

## 📑 Progres Week 1: Inisialisasi & Perencanaan
Pada minggu pertama, fokus utama adalah perencanaan arsitektur perangkat lunak dan inisialisasi lingkungan pengembangan.

### Fitur & Batasan pada Milestone ini:
- Perencanaan struktur project modular.
- Konfigurasi parameter global game seperti dimensi layar, FPS limit, warna dasar UI, dan parameter fisika dasar di file `config.py`.
- Pembatasan dependency eksternal hanya menggunakan `pygame`.

### 📂 Struktur Proyek pada Week 1:
```
📦 BilliardMaster
┣ 📜 config.py            # Konstanta Global (Dimensi layar, FPS, warna UI dasar)
┣ 📜 requirements.txt     # Library dependency (hanya pygame)
┗ 📜 README.md
```

---

## 🛠️ Instalasi & Menjalankan Program

### 1️⃣ Prasyarat
- Python **3.8 atau lebih baru**

### 2️⃣ Instalasi Dependency
Jalankan perintah berikut di terminal:
```bash
pip install -r requirements.txt
```
